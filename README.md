# Zoha Faiz — Portfolio

A complete responsive portfolio in plain HTML, CSS and JavaScript. No installation, build process, API keys or paid packages required.

## Open locally
Extract the ZIP and double-click index.html. For clipboard support and normal HTTP behavior, optionally run `python -m http.server 8000` in this folder, then open http://localhost:8000.

## Deploy on Vercel
1. Create a new repository in your personal GitHub account.
2. Upload the contents of this folder. index.html, styles.css, script.js and assets must be at the repository root, rather than inside an extra nested folder.
3. Sign in at https://vercel.com and choose Add New → Project.
4. Import the GitHub repository.
5. Framework preset: Other. Leave the build command empty; output directory should be the repository root (`.`).
6. Deploy. Vercel will provide a .vercel.app URL. Change the project name in Vercel if you want a different available URL.

Vercel's Hobby plan is free for personal, non-commercial projects within its usage limits. Review current terms at https://vercel.com/pricing. No custom domain purchase is necessary for a .vercel.app URL.

## Edit the content
- index.html: homepage copy, contact links, project cards, skills and experience.
- styles.css: colors, type, spacing, responsive layout and animations.
- script.js: project case studies, animated data network and interactions.
- assets/ZohaFaiz_INTERN_CV.pdf: replace this file to update the downloadable CV.

Color tokens are at the top of styles.css. Google Fonts is optional: if it cannot load, the page uses sans-serif fallbacks. All portfolio functionality is local; contact opens an email client, and Copy email uses the browser clipboard when available, with a visible fallback.

Content uses the supplied CV and updated TA responsibilities. Customerly is clearly marked as in development. Project illustrations are schematic, not screenshots or benchmark charts. The CV is the original provided file and still has its original summary/experience; update it separately if desired. Individual repository links were not supplied, so project buttons open case studies rather than invented links. The GitHub profile and LinkedIn links are from the supplied CV.

Accessibility: keyboard navigation, native accessible project dialogs, skip link, reduced-motion support, and responsive layout. The original CV contains your phone number; visitors downloading it can see the original contents.
